We are moving from a world too centralized to a world, more decentralized.

One of the key designs is local first.


Here I propses the stages to implement fully functional local first software that facilitate small medium and large/gobal usage.

every next stage comes with previous stage's features or requirements.

stage one:

- software runs without any network connecting including local network and internet.


stage 2:

- software can sync data between different devices, either through an encrypted/unencrypted server, LAN, bluetooth, the network protocol can be fully p2p or distributed, or centralized


stage 3:

- sfotware can be involved without open sourced code, either through AI, or one or more maintaining team
